# Lab2 IA

## Description

Ce projet a été réalisé dans le cadre des travaux pratiques en Intelligence Artificielle (IA).

## Objectifs

* Découvrir les concepts de base de l'intelligence artificielle.
* Réaliser les exercices du TP.
* Mettre en pratique les notions étudiées en cours.

## Technologies utilisées

* Python
* Jupyter Notebook

## Installation et exécution

1. Télécharger ou cloner ce dépôt GitHub.
2. Installer Python et Jupyter Notebook.
3. Ouvrir les fichiers du projet avec Jupyter Notebook.
4. Exécuter les cellules du notebook.
